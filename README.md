# 🧠 3D Interactive Art Practice with Three.js & React

This repo is my personal playground where I practice creating 3D interactive art using modern web tools. The goal is to master the necessary steps for building a fully responsive, performant 3D portfolio website that works smoothly on both mobile and desktop devices.

> ## 🚧 Current Status
> In progress – Just practicing!<br>
> Trying out different scene setups, effects, loading models from Blender, and improving user interaction.

## 🎯 Goals

- Learn and explore:

    - three.js for 3D rendering

    - react-three-fiber for using Three.js declaratively with React

    - @react-three/drei for useful helpers/components

    - framer-motion for smooth animations in the UI

    - React itself to glue everything together


- Integrate 3D models made with Blender

- Make the site responsive for mobile and desktop users

- Add performance scaling (e.g. reduce quality when FPS drops)

- Practice lighting, composition, interaction, and animation

- Build up the core components for my future 3D portfolio website

## 🧰 Tools / Libraries

| Library / Tool         | Description                                       |
|------------------------|---------------------------------------------------|
| [`three.js`](https://threejs.org/)             | Core 3D rendering engine                           |
| [`react-three-fiber`](https://github.com/pmndrs/react-three-fiber) | React renderer for Three.js – declarative 3D    |
| [`@react-three/drei`](https://github.com/pmndrs/drei)     | Helpers and abstractions for R3F (e.g., controls, envs) |
| [`framer-motion`](https://www.framer.com/motion/)         | UI animations and transitions                     |
| [`React`](https://reactjs.org/)                          | Component-based UI framework                      |
| [`Blender`](https://www.blender.org/)                     | 3D modeling, rigging, texturing, and compositing  |


## 📱📺 Responsiveness & Performance
- Layout adjusts across devices (mobile + desktop)

- Scene complexity and effects will adapt to FPS:

    - If frame rate drops, the system will lower visual quality to maintain smooth performance

    - Goal is a seamless experience even on low-end phones

## 🔮 Long-Term Vision

This project is a training ground. The end goal is to create a visually unique, interactive portfolio that:

- Represents me as a dev + artist

- Runs fast and looks great

- Feels alive and reactive to user interaction
